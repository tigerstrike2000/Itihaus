# Itihaus

A collection of interactive educational projects, including strategy games and learning tools.

## Projects

### Economic History Game
An interactive, real-time strategy game where students manage ancient empires based on real historical civilizations. Learn about resource management, trading, economic systems, and empire building.

**Key Features:**
- 5 Playable Civilizations (Egypt, Rome, Persia, Greece, Mesopotamia)
- Real-time resource management
- Dynamic market economy
- Population and happiness systems
- Interactive building and trading

**Play Now:** Open `/economic-history-game/index.html`

**Learn More:** See `/economic-history-game/README.md`

## Technologies Used

- **Frontend**: HTML5, CSS3, Vanilla JavaScript
- **Game Engine**: Custom JavaScript game loop
- **Storage**: localStorage (for future save states)
- **Compatibility**: Modern browsers (Chrome, Firefox, Safari, Edge)
